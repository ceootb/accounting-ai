# Tips: Recurring (Repeating Transactions)

> **Recurring** = a feature to record **routine/repeating vouchers** (monthly, quarterly) without
> retyping them each period. It works for **Sales Invoices, Purchase Invoices, and Journal Vouchers**.

## Why use recurring

Its main purpose is to **avoid forgetting** routine journals / adjustments that stay the same each
period. Once set up, every future period is already prepared, so routine entries don't slip through.

**Example uses:**
- **Sales Invoice** → a **monthly commission** billing to a customer.
- **Purchase Invoice** → routine bills: **water, electricity, phone**, rent, etc.
- **Journal Voucher** → routine adjustments, e.g. a **tax allowance on employee income tax (PPh 21)**.

## What to prepare

Because recurring prepares vouchers for future periods, the **Accounting Period in Company Info needs
to be extended** (typically set **12 months ahead**). After that, the vouchers for all periods **can
be created right now**, all at once, until the grid is filled — no need to wait for each period's date.

## Important note

> Recurring is **not a tool for estimating cash flow**. The amounts on future-period vouchers are
> **minimalist accrual placeholders** — their only role is a **reminder** so that routine
> journals/adjustments aren't forgotten, **not** a cash-flow projection.

> *This is an efficiency tip, not a new accounting rule — the journal produced is the same as an
> ordinary voucher.*
